## Technology plan
- Frontend: existing HTML, CSS and JavaScript
- Backend: Node.js with Express
- Database: SQLite for the initial prototype
- Authentication: secure server-side sessions
- API design: versioned REST endpoints
- Deployment: HTTPS-enabled hosting

## Development order
1. Preserve and document the existing website.
2. Build the responsive frontend foundation.
3. Add backend and database.
4. Implement authentication and authorization.
5. Build modules incrementally with tests.
6. Integrate external services only when configured.
7. Deploy with HTTPS, backups and monitoring.

## Security
- Never expose API secrets in frontend code.
- Validate inputs on the server.
- Apply access controls and rate limits.
- Minimize personal data collection.
- Use authorized payment providers for real payments.
- Clearly distinguish demos from live services.
- Use official government sources and links.

## Initial limitations
Search, maps, email, AI, storage and payments need
real providers or backend implementations before they
can be considered fully functional.
